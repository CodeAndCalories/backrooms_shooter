# CLAUDE.md

## Session start
Read BACKROOMS_STATE.md before any work — it is the living state doc.
The HARD CONSTRAINTS section in it applies to every change.
Update its CURRENT STATE section at the end of each session.

First time on this project (or a new model): also read PROJECT_GUIDE.md — the durable
"how & why" handoff (working method, architecture map, why the constraints exist,
failure modes, tuning knobs, quality bar). BACKROOMS_STATE.md = current state;
PROJECT_GUIDE.md = how the project is run.
